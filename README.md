# 🐛 SwormVlood

**Roguelike** с элементами **Twin Stick Shooter** и кооперативным мультиплеером для 2-4 игроков.

Разрабатывается на **Godot 4.6.1** (GDScript).

## 🎮 Особенности

- **4 уникальных класса**: Мечник, Лучник, Маг, Паладин
- **Процедурная генерация подземелий**
- **Кооперативный мультиплеер** (локальная сеть, 2-4 игрока)
- **Система лута**: оружие, зелья, монеты
- **7 этажей + финальный босс**

---

## 🛠️ Технический стек

- **Движок**: Godot Engine 4.6.1
- **Язык**: GDScript
- **Физика**: Jolt Physics (2D)

## 🎯 Управление

| Действие | Клавиши |
|----------|---------|
| Движение | `W` `A` `S` `D` или стрелки |
| Атака | ЛКМ (левая кнопка мыши) |
| Способность | ПКМ (правая кнопка мыши) |

## 📁 Структура проекта

```
sworm-vlood/
├── scenes/          # Сцены (.tscn)
│   ├── player/      # Игрок
│   ├── enemies/     # Враги
│   ├── levels/      # Уровни
│   ├── items/      # Предметы (стрелы, файрболлы)
│   ├── ui/          # Интерфейс (меню, HUD)
│   └── game/        # Основная сцена игры
├── scripts/         # GDScript код
│   ├── autoload/   # GameManager (глобальное состояние)
│   ├── components/ # Переиспользуемые компоненты
│   ├── player/     # Логика игрока
│   ├── enemies/    # Логика врагов
│   ├── items/      # Логика предметов
│   └── ui/         # Логика интерфейса
├── assets/         # Ассеты (временно — квадраты)
└── docs/           # Документация
```
