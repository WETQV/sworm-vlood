# Сетевой стенд

Автоматические замеры кооператива (P0 из [ТЗ аудита сети](../../docs/network_audit_requirements.md)). Каждый участник — отдельный процесс Godot на этой машине; персонажами управляют боты через настоящий `Input`.

## Запуск

Нужны Godot (консольная версия) и Python 3 без дополнительных пакетов. Путь к Godot берётся из `GODOT_CONSOLE` или параметра `-Godot`.

```powershell
# Один прогон: 2 игрока, подтягивание в комнату, пинг ~100 мс, джиттер ±10 мс, 1% потерь
powershell -ExecutionPolicy Bypass -File tests/net/run.ps1 -Players 2 -Scenario pull -Latency 50 -Jitter 10 -Loss 1

# Вся матрица (сценарии × профили сети × 2/4 игрока) в один отчёт
powershell -ExecutionPolicy Bypass -File tests/net/matrix.ps1 -Report docs/net_reports/новый_отчёт.txt

# 10 смен этажа подряд вчетвером
powershell -ExecutionPolicy Bypass -File tests/net/run.ps1 -Players 4 -Scenario floors -Floors 10 -Latency 50 -Jitter 10 -Loss 1
```

`-Latency` — задержка в одну сторону (RTT ≈ 2×), её вносит UDP-прокси между клиентами и хостом. Хост с прокси не связан и видит только задержку клиентов.

## Сценарии

| Сценарий | Что проверяет |
| --- | --- |
| `walk` | Все бродят у старта: ошибка позиции, рывки и дрожание удалённых игроков |
| `pull` | Хост телепортируется в боевую комнату, остальных подтягивает: откаты после телепорта |
| `combat` | Бой с атаками и рывками: принятие/отклонение запросов хостом, трафик |
| `floors` | Многократная смена этажа: зависания, рост числа узлов, устаревшие сообщения |
| `role=solo` | Одиночная игра без сети: урон в обе стороны, зачистка комнаты |

## Что в отчёте (`analyze.py`)

- **Скачки у владельца** — перемещения своего персонажа больше 40 px за кадр (телепорт или коррекция хоста).
- **Ошибка** — расстояние между тем, где наблюдатель видит игрока, и тем, где тот был у владельца в тот же момент (p50/p95/max). Включает задержку сети и интерполяции.
- **Скачки / ложные скачки** — рывки больше 40 px за кадр у наблюдателя; ложные — те, которых у владельца не было.
- **Дрожание** — p95 разницы между смещением за кадр у наблюдателя и у владельца. Показывает неровность движения.
- **RTT, потери, трафик, пакеты, время кадра** — медианы по секундам.
- **NETSTATS** в `*_events.csv` — счётчики `NetworkManager.net_stats` (принятые/отклонённые запросы и т. п.).

Все процессы пишут системное время, поэтому позиции разных процессов сравнимы. Логи лежат в `%TEMP%\sworm_net_*`.
